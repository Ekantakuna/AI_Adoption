# Governance assessments

This area contains evidence-backed AI and data governance assessments. It separates AS-IS observations, TO-BE definitions, gap findings and progress reviews so conclusions and changes remain traceable over time.

- `current-state/` records evidence-backed AS-IS assessments.
- `target-state/` records reviewed TO-BE assessment material and rationale.
- `gap-analysis/` compares referenced current and target states.
- `progress/` stores later reassessments and control-effectiveness reviews.

Assessment headers and granular findings are canonical in `registers/governance-assessments.yaml` and `registers/governance-findings.yaml`.
