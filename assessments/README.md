# Assessments

This directory is scaffolded for future traceable current-state, target-state,
gap, maturity, and impact assessments. Its `gaps/` and `target-state/`
subdirectories are empty, and no assessment schema, identifier, method,
lifecycle, record, or validator is implemented. The approved initial mode is
explicitly unscored and schema-validated in `config/scoring_models.yaml`; this
entry control is not an assessment method or assessment implementation.

Assessments are interpretations derived from reviewed evidence and knowledge;
they are not evidence themselves. AI agents may draft them, but an authorized
human must approve current-state conclusions and target-state commitments.
