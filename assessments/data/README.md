# Data readiness assessments

This area contains evidence-backed evaluations of data readiness, products, capabilities, governance extensions, quality, metadata and observability.

- `current-state/`
- `target-state/`
- `use-case-and-product-readiness/`
- `governance-and-capabilities/`
- `quality/`
- `metadata-and-lineage/`
- `observability/`

Canonical assessment and finding records live in `registers/data-assessments.yaml` and `registers/data-findings.yaml`.
