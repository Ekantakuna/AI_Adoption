# Engineering platform assessments

This area contains evidence-backed evaluations of engineering capabilities, architecture, technical options, observability, AI UX and catalogue readiness.

- `current-state/` evaluates evidenced AS-IS capabilities and practices.
- `target-state/` evaluates proposed or approved target characteristics.
- `architecture-and-options/` evaluates architecture conformance and technical alternatives.
- `observability-and-operations/` evaluates monitoring and operational readiness.
- `ai-ux/` evaluates human-AI interaction design.
- `catalogue-readiness/` evaluates inventory, documentation, assurance and lifecycle processes.

Canonical assessment records live in `registers/engineering-assessments.yaml`.
