# Decision environment assessments

This area contains evidence-backed evaluations of decision capability, quality, authority, controls, observability and learning effectiveness.

- `current-state/` evaluates evidenced AS-IS practices.
- `target-state/` evaluates proposed or approved target characteristics.
- `gap-analysis/` compares reviewed current and target states.
- `decision-quality/` evaluates decision process and outcome quality.
- `learning-effectiveness/` evaluates whether feedback improves future decisions.

Canonical assessment headers live in `registers/decision-environment-assessments.yaml`. No assessment conclusion exists until evidence and human review requirements are met.
