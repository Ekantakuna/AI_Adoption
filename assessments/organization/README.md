# Organization assessments

This area contains evidence-backed assessments of the organization and AI value operating model across ICT, Business, Legal and Compliance.

- `current-state/` retains dated AS-IS assessments.
- `target-state/` retains reviewed TO-BE definitions and rationale.
- `gap-analysis/` compares current evidence with a versioned target profile.
- `progress/` retains later reassessments and implementation progress.

Canonical assessment headers and findings belong in `registers/organization-assessments.yaml` and `registers/organization-findings.yaml`.
