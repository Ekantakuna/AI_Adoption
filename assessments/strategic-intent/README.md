# Strategic-intent assessments

This area contains evidence-backed strategy, scenario, execution and outcome assessments.

- `context-and-baseline/` establishes the evidence-backed strategic context.
- `scenarios-and-simulations/` retains reviewed scenario and simulation analysis.
- `execution-progress/` evaluates objectives, initiatives, milestones, dependencies and early indicators.
- `outcomes-and-success/` evaluates critical success factors and realized outcomes.
- `strategy-review/` evaluates assumptions, choices, target-state progress and adaptation needs.

Canonical assessments and findings belong in `registers/strategy-assessments.yaml` and `registers/strategy-findings.yaml`.
