# Prompts

This directory contains reusable, reviewable task instructions. The ingestion,
analysis, synthesis, reporting, publication, and system subdirectories are
empty scaffolds; their presence does not implement those workflows.

`codex/` contains the currently implemented prompt library and its operating
rules. Prompt text is an instruction input, not proof that the requested task
ran or that its outputs were approved. Repository-wide `AGENTS.md` rules take
precedence over saved prompts.
