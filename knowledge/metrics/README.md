# Knowledge metrics

- **Purpose:** define measures supported by evidence; values and project tracking belong in their governed records.
- **Accepted:** Markdown definitions covering calculation, unit, interpretation, and schema-valid front matter.
- **Prohibited:** invented measurements, untraceable values, project status, and assessment conclusions.
- **Identifier prefix:** `METRIC`; use `METRIC-NNNNNN` and never reuse an ID.
- **Template:** `metric-template.md` (`METRIC-000000` is not production).
- **Evidence requirement:** at least one valid `EVID` reference supporting the definition.
- **Review requirement:** AI output starts as `draft` or `needs_review`; authority requires identified human review.
- **Upstream inputs:** atomic evidence, concepts, and approved measurement methods.
- **Downstream consumers:** assessments, progress views, outlook content, reports, and presentations.
