# Ecosystem and sourcing semantic layer

This area explains the reusable provider and sourcing lifecycle relationships. Canonical records live in YAML registers.

```text
partnership requirement + strategic choice
  -> sourcing case
  -> candidate providers + offerings
  -> evaluation + due diligence
  -> selection decision
  -> agreement -> solution + obligations + controls + metrics
  -> performance review -> remediate, renew, recompete or exit
  -> exit plan -> portability + continuity + transition
```

Risks, controls, metrics, dependencies, solutions, capabilities, stakeholders and decisions remain shared records. Provider and offering claims require source evidence; evaluation scores, due-diligence outcomes and performance conclusions require human review.
