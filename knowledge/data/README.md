# Data semantic layer

This area explains reusable relationships between data-domain records. Canonical records remain in YAML registers.

```text
AI use case + implementation + decision need
  -> data requirement
  -> data product + access + intended-use constraints
  -> data capability + analytics and lifecycle practices
  -> quality framework + quality rules
  -> metadata + semantics + lineage + provenance
  -> observability checks
  -> assessment -> finding -> data action -> initiative
```

AI-specific data-governance requirements reference canonical governance artifacts, roles, risks and controls. Platform solutions and architecture remain in engineering; implemented facts remain in current state.
