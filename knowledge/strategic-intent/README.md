# Strategic-intent semantic layer

This area explains the traceable relationships used to construct, challenge, execute and evolve the AI strategy. Canonical facts and proposals live in YAML registers.

```text
AI strategy
  -> vision + transformation thesis + target state
  -> strategic objectives + choices + hypotheses

choice -> challenged by scenarios and simulations
objective -> depends on capabilities and execution -> measured by outcomes and indicators
critical success factor -> monitored by leading indicators
decision-intelligence target -> realizes the transformation thesis
execution plan -> coordinates initiatives, milestones and dependencies
assessment -> produces finding -> triggers intervention or strategy change
change event -> links strategy versions and preserves rationale
```

The five decision-intelligence properties are controlled concepts, not proof that they exist. Strategy records must retain source evidence, assumptions, alternatives, review state and version lineage.
