# Organization semantic layer

This area explains the reusable organization and AI value-operating-model relationships. Canonical records live in YAML registers.

```text
organization target
  -> realized through operating model
  -> composed of units, roles, networks and practices

role -> belongs to or connects units -> requires competencies and capacity
community or champion network -> connects constituencies and domains
practice -> coordinates work stages -> produces value-flow outcomes
partnership requirement -> fills a capability or capacity gap
tool requirement -> enables practices, networks, coordination and measurement
assessment -> produces evidence-backed finding
approved gap -> drives organization action -> changes the target system
```

Organization records link to governance, people and culture, data, engineering, security, value management, use cases, sourcing and maturity through controlled domain identifiers. The semantic model is provisional and must be refined through approved evidence analysis and collaboration.
