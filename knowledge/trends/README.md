# Trends

- **Purpose:** represent evidence-backed patterns over time without turning them into forecasts automatically.
- **Accepted:** Markdown trend records with direction, timeframe discussion, and schema-valid front matter.
- **Prohibited:** single observations labelled as trends, unsupported forecasts, or approved outlook conclusions.
- **Identifier prefix:** `TREND`; use `TREND-NNNNNN` and never reuse an ID.
- **Template:** `trend-template.md` (`TREND-000000` is not production).
- **Evidence requirement:** at least one valid `EVID` reference.
- **Review requirement:** AI output starts as `draft` or `needs_review`; authority requires identified human review.
- **Upstream inputs:** atomic evidence, metrics, and concepts.
- **Downstream consumers:** relationships, assessments, outlook analysis, reports, and presentations.
