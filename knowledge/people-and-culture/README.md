# People and culture semantic layer

This area explains the reusable relationships used for AI change planning, workforce impact, literacy, readiness and reporting. Canonical facts live in YAML registers.

```text
change plan
  -> phases and actions
  -> awareness campaigns + literacy programs + readiness interventions

workforce impact assessment -> granular role/task/competency impacts
literacy program -> develops competencies for roles and audiences
business champion network -> activates literacy and gathers feedback
readiness assessment -> aggregated findings -> targeted actions
action + campaign + program -> metric values -> append-only snapshot -> report
```

Stakeholders, organizational roles, champion networks, capabilities, competencies, initiatives, milestones, risks and metrics are shared records referenced by stable IDs. The model is provisional and contains no employee-level conclusions.
