# Frameworks

- **Purpose:** define evidence-backed models for organizing or evaluating knowledge.
- **Accepted:** a Markdown framework with purpose, components, boundaries, and schema-valid front matter.
- **Prohibited:** assessment results, unsupported methodology, and publication-only diagrams.
- **Identifier prefix:** `FRAME`; use `FRAME-NNNNNN` and never reuse an ID.
- **Template:** `framework-template.md` (`FRAME-000000` is not production).
- **Evidence requirement:** at least one valid `EVID` reference.
- **Review requirement:** AI output starts as `draft` or `needs_review`; adoption requires authorized human approval.
- **Upstream inputs:** atomic evidence, concepts, terms, and applicable methods.
- **Downstream consumers:** assessments, outlook analysis, reports, and presentations.
