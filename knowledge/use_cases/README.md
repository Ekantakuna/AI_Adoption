# Use cases

- **Purpose:** describe evidence-backed applications and intended outcomes, distinct from approved initiatives.
- **Accepted:** Markdown use-case records with problem, outcome, boundaries, and schema-valid front matter.
- **Prohibited:** unsupported implementation claims, project commitments, solution approvals, or publication-only narratives.
- **Identifier prefix:** `USECASE`; use `USECASE-NNNNNN` and never reuse an ID.
- **Template:** `use-case-template.md` (`USECASE-000000` is not production).
- **Evidence requirement:** at least one valid `EVID` reference.
- **Review requirement:** AI output starts as `draft` or `needs_review`; authority or commitment requires identified human approval.
- **Upstream inputs:** atomic evidence, concepts, metrics, risks, and frameworks.
- **Downstream consumers:** relationships, value assessments, outlook content, initiatives, reports, and presentations.
- **Current production set:** `USECASE-000001` is an internal AI-origin record
  approved by MZ for its stated semantic use during Stage 10.
  `USECASE-000002`–`000003` remain internal AI-origin drafts in `needs_review`;
  folder placement and source wording do not by themselves verify operational
  implementation.
