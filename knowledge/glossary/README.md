# Glossary terms

- **Purpose:** maintain evidence-backed definitions used consistently across the repository.
- **Accepted:** one Markdown term record with schema-valid front matter and a concise definition.
- **Prohibited:** unsupported definitions, raw excerpts, duplicate terms, and unreviewed claims presented as authoritative.
- **Identifier prefix:** `TERM`; use `TERM-NNNNNN` and never reuse an ID.
- **Template:** `glossary-entry-template.md` (`TERM-000000` is never a production record).
- **Evidence requirement:** at least one valid `EVID` reference.
- **Review requirement:** AI output starts as `draft` or `needs_review`; authority requires identified human review.
- **Upstream inputs:** atomic evidence and existing controlled terminology.
- **Downstream consumers:** knowledge records, assessments, documentation, reports, and presentations.
