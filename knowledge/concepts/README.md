# Concepts

- **Purpose:** describe interpreted, reusable ideas supported by atomic evidence.
- **Accepted:** one Markdown concept with schema-valid front matter, scope, and implications.
- **Prohibited:** raw extraction, unsupported factual claims, assessments, or generated publication copy.
- **Identifier prefix:** `CONCEPT`; use `CONCEPT-NNNNNN` and never reuse an ID.
- **Template:** `concept-template.md` (`CONCEPT-000000` is not production).
- **Evidence requirement:** at least one valid `EVID` reference.
- **Review requirement:** AI output starts as `draft` or `needs_review`; authority requires identified human review.
- **Upstream inputs:** reviewed or reviewable evidence and glossary terms.
- **Downstream consumers:** frameworks, relationships, assessments, outlook content, and publications.
