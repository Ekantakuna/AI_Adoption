# Agentic-native AI adoption project

This project is designed to become agent operated while remaining human accountable.

Agents may prepare plans, perform authorized repository work, validate outputs, maintain traceability and propose decisions. Humans retain authority for scope, source access, classification, processing routes, strategic choices, risk acceptance, publication, commit and push.

Canonical workflow definitions use `AWF-*`; append-only execution traces use `AWRUN-*`.

The controlled workflows are documented under `workflows/`. Adoption of these structures does not authorize source-content access or autonomous external action.
