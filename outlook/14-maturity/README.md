# Maturity and execution

This folder contains framework-based maturity evaluation associated with the unified `maturity_execution` taxonomy domain. Roadmap material for the same domain is maintained in `../15-roadmap/`.

## Included scope

- the selected maturity framework and its component models;
- model dimensions, levels, characteristics, criteria and scoring methods;
- overall AI adoption maturity with emphasis on Generative AI adoption and scaling;
- baseline, progress and target assessments;
- progress from new use-case adoption and AI-enabled business-process transformation;
- progress towards AI vision and strategic intent;
- qualitative arguments and quantitative measures supporting every maturity judgement;
- limitations, confidence and unresolved evidence gaps.

The section must not state a maturity level without approved findings and evidence. Historical assessments remain available for comparable progress monitoring.
