# Data readiness

This domain develops the data capabilities, products, governance extensions, quality, metadata, analytics and observability required for reliable and responsible AI.

- `01-data-strategy-scope-and-principles/` defines boundaries and principles.
- `02-readiness-target-and-plan/` defines TO-BE readiness and improvement planning.
- `03-data-capabilities-and-analytics/` defines analytics and data capabilities for AI.
- `04-data-requirements-products-and-access/` defines demand, products, interfaces and access.
- `05-data-governance-for-ai/` defines AI-specific extensions to governance requirements.
- `06-ai-data-quality-framework/` defines quality dimensions, rules, thresholds and evidence.
- `07-metadata-semantics-lineage-and-provenance/` defines meaning, traceability and documentation practices.
- `08-data-observability-and-reliability/` defines operational signals, checks and response.
- `09-data-lifecycle-rights-and-retention/` defines lifecycle, purpose, rights and disposition requirements.
- `10-assessment-roadmap-and-reporting/` supports evidence-backed assessment and improvement.
