# Value management and portfolio prioritization

This folder contains outlook material associated with the `value_management` taxonomy domain.

## Included scope

- prioritization of initial AI use cases
- value hypotheses and expected outcomes
- AI portfolio scoring and prioritization
- value baselines, targets and metrics
- value tracking for pilots and implemented use cases
- realized-benefit monitoring
- AI value-monitoring systems
- portfolio review and reprioritization

Use-case catalogue entries and implementation descriptions belong to the separate `use_cases` domain.
