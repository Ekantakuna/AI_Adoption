# Value management and use cases

This report section groups two separate taxonomy domains. They share a publication section but retain distinct scope, evidence, analysis and recommendations.

- `value-management/` covers `value_management`: initial-use-case prioritization, value definition, portfolio scoring, value tracking, realized-benefit monitoring and AI portfolio governance.
- `use-cases/` covers `use_cases`: possible and implemented Traditional AI, GenAI/LLM and Agentic AI applications, with emphasis on telecom, IT product development and product engineering.

Use-case descriptions belong in `use-cases/`. Prioritization decisions and value-monitoring methods belong in `value-management/`.
