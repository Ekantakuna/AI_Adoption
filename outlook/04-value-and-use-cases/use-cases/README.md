# AI use cases

This folder contains outlook material associated with the `use_cases` taxonomy domain.

## Included scope

- Traditional AI use cases
- Generative AI and LLM use cases
- Agentic AI use cases
- telecom-specific applications and implications
- IT product-development applications
- product-engineering applications
- actors, workflows, dependencies and implementation considerations

Portfolio prioritization, value definition and realized-benefit tracking belong to the separate `value_management` domain.
