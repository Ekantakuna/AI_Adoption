# Current-state baseline

This folder contains evidence-backed AS-IS analysis associated with the `current_state` taxonomy domain.

## Included scope

- implemented and piloted AI use cases;
- adopted Traditional AI, GenAI/LLM, Agency and Agentic AI techniques;
- deployed in-house, vendor, open-source and cloud-managed solutions;
- data, model, cloud and integration architecture;
- data and model governance;
- security, monitoring and human oversight;
- implementation lifecycle, scale and current operating status.

Potential use-case patterns belong to `use_cases`. Prioritization and realized-value tracking belong to `value_management`. Current-state conclusions must be traceable to reviewed implementation records, snapshots and evidence.
