# Presentations

This directory is scaffolded for future presentation source, reusable themes,
and generated output. `source/` and `themes/` are empty;
`generated/` contains only a tracked `.gitkeep`, and generated files are ignored.
No presentation identifier, template, renderer, lifecycle, or validator is
implemented.

Presentations are replaceable derivatives of approved publication or canonical
content. They must not become the only copy of a claim, evidence, approval, or
decision, and publication-ready executive claims require authorized human
review.
