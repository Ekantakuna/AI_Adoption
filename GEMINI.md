# Gemini repository guidance

Read and follow `AGENTS.md` before working in this repository. `AGENTS.md` is the canonical agent-guidance file and applies to all tools and assistants.

In particular:

- never invent company facts;
- distinguish facts, assumptions, inferences, and recommendations;
- preserve source provenance and stable record IDs;
- follow `project/information-handling.md`;
- do not process source documents before classification review;
- do not add register records before the register-specific schema is approved;
- do not commit or push without explicit permission.
